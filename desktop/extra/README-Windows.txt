引魂宅 · 红妆劫 —— Windows 版
================================

【怎么开始】
  1. 解压 YinHunZhai-win-x64.zip 到任意文件夹（路径里不要有奇怪符号没关系，中文路径可以）
  2. 双击 YinHunZhai.exe
  3. 标题页选难度 → 推门而入 → 点一下画面锁定鼠标

【没有安装、没有依赖】
  整个游戏就在这一个文件夹里，绿色免安装。拷到 U 盘、发给朋友都能直接跑。
  需要 Windows 10 及以上，64 位。要 WebGL（任何近十年的核显都够）。

【存档在哪】
  %APPDATA%\yinhunzhai\Local Storage\leveldb
  菜单「游戏 → 打开存档所在文件夹」可直达。
  想换机器继续玩，把这个文件夹一起拷走即可。

【常用键】
  WASD 行走      Shift 疾走（脚步响，她听得见）
  E     查看/拾取/动手
  Ctrl  屏息（藏身时按住）
  H     香炉前燃香（平阴气，方圆之内她不敢入）
  F     火折子
  Tab/J 囊中物 / 引魂簿
  G     问柳三娘卖关子（用阴气换提示）
  F11   全屏       Alt 唤出菜单栏

【卡顿或黑屏】
  · 右键 exe → 属性 → 兼容性，勾「禁用全屏优化」
  · 双显卡笔记本：在显卡控制面板里把本程序指定为「高性能」
  · 仍不行：用命令行加参数启动  YinHunZhai.exe --disable-gpu

【真出问题】
  窗口标题栏菜单：游戏 → 重进本宅；或删掉上面那个存档文件夹重来。

【内容提示】
  含惊吓、幽闭与民俗恐怖元素，建议戴耳机游玩。
  所有女性角色均为成年人设，魅惑止于氛围与暗示，不含露骨内容。
