# 引魂宅 · 红妆劫

中式恐怖 3D 第一人称密室逃脱。**全部资产程序化生成**——建模、贴图、音乐、音效无一使用外部素材文件，仓库里没有一张图片、没有一段音频。

民国十七年秋，你在槐宅门外醒来。宅中今夜要办一桩冥婚，聘的是一位从未谋面的活人——你。十道机关，六礼已成其五。天一亮，盖头就要落到你头上。

**在线玩**：https://zjhZJH-pron.github.io/yinhunzhai/

## 手机 / 平板

本作是 **PWA**，手机可直接装成独立应用：全屏运行、有自己的图标、从主屏幕启动、离线可玩。

1. 用手机浏览器打开上面的在线地址
2. **安卓 Chrome**：右上角菜单 →「添加到主屏幕」/「安装应用」
   **iOS Safari**：分享按钮 →「添加到主屏幕」

触控方案（手机浏览器不支持 Pointer Lock，所以整套输入是另做的）：

| 操作 | 方式 |
|---|---|
| 行走 | 左半屏**浮动摇杆**——手指按在哪儿，哪儿就是杆心 |
| 转视角 | 右半屏拖拽 |
| 交互 | **直接点物件**（屏幕空间拾取），或点右下「交互」键 |
| 屏息 | 按住「屏息」键 |
| 燃香 / 火折子 / 背包 / 引魂簿 / 问柳三娘 | 右侧按钮簇 |

多指并行：边走、边看、边按住屏息是常态，所以输入按 pointerId 分轨处理。

低配档自动生效（`pointer:coarse` 或 `?mobile=1`）：关阴影、贴图分辨率减半、灯笼蜡烛不建动态点光而靠自发光撑场、粒子与后处理降采样。

> 建议横屏。竖屏会显示转向提示。

## 键盘鼠标

| 键 | 作用 |
|---|---|
| `W A S D` | 行走 |
| `Shift` | 疾走 —— 脚步响亮，**她听得见** |
| `E` | 查看 / 拾取 / 动手 |
| `Ctrl` | 屏息 —— 藏身时她走近，屏息可躲过 |
| `H` | 香炉前燃香：平定阴气，方圆之内她不敢入 |
| `F` | 火折子（照亮，也照得见她） |
| `Tab` / `J` | 囊中物 / 引魂簿 |
| `G` | 问柳三娘卖关子 —— **用阴气换提示** |
| `F11` | 全屏 · `Alt` 唤出菜单栏 |

**魂灯**即你的心智。阴气涨于：她靠近、答错机关、黑暗、被抓住。灯灭则魂散，从最近的香炉前重新起身——已解开的机关不会白破。

三档难度：夜探（可循迹而行）/ 凶宅（阴气侵蚀·无指引）/ 夺舍（她一直在看着你）。

### 三个结局

- **出门** —— 六礼齐备与否，决定她是「未嫁之鬼」还是别的
- **替嫁** —— 宅子从头到尾准备的都是你
- **同穴**（隐）—— 需先拔净镇魂钉、且身上有《往生咒》残卷

## 自己构建

需要 Node 18+，**只用 Node 内置模块，无需 `npm install`**。

```bash
node desktop/make-icon.js     # → desktop/icon.png
node build.js                 # → game.html（单文件，可双击）
```

打三平台桌面包（需先下载对应平台的 Electron 预编译 zip）：

```bash
node desktop/pack-electron.js <electron-<平台>.zip> <out.zip> <appDir>
```

`pack-electron.js` 对 mac/linux 采用**只追加**策略：原 zip 的字节与中央目录项原样保留，只在末尾追加 `resources/app/` 并重写中央目录。因为 darwin 包里有 14 个符号链接（`Electron Framework.framework/Versions/Current` 等）和 15 个执行位，linux 有 8 个执行位（含 `chrome-sandbox`）——在 Windows 上解压再压缩会丢掉这些元数据，得到的 `.app` 在 mac 上直接起不来。Windows 包没有这两类元数据，走正常的解压→改名→再压缩。

### 自检

打包产物可以真跑一遍，不用人点：

```bash
YinHunZhai.exe --smoke-test
# 写出 %TEMP%\yinhunzhai-smoke.json，成功退出码 0
```

## 谜题与文化考据

谜题的答案不是藏在某个抽屉里，而是要你自己推。考据点：

| 机关 | 依据 |
|---|---|
| 六礼上供 | 《仪礼·士昏礼》六礼：纳采用雁→问名→纳吉→纳征→请期→亲迎 |
| 五方灯阵 | 五方正色 东青·南赤·中黄·西白·北黑；再按五行相生 木火土金水 点灯 |
| 祖先牌位 | 《礼记》左昭右穆、代不移序、居中者不迁；字辈诗定辈分 |
| 井栏杆秤 | 五行生数「水一火二木三金四土五」× 方色 → 五石各重几两，凑十三两 |
| 五运配药 | 「实则泻其子…今魂不虚亦不实，泻其所不胜」= 泻**克我者**；五味属行 酸木苦火甘土辛金咸水 |
| 铜镜光路 | 三面活镜把烛光引到镇魂匣（／＼反射几何） |
| 工尺谱 | 工尺七调配五音：上=宫 尺=商 工=角 凡=徵 六=羽；听音补末句 |
| 安神符 | 「起西北天门，历三台而上，落鬼足于下」——一笔到底，烛尽前完成 |
| 盖头灯谜 | 拆字：一口咬掉牛尾巴＝告；千里相逢＝重；人在口中＝囚 |
| 九重门闩 | 《尚书大传》洛书：戴九履一，左三右七，二四为肩，六八为足，五居中央——纵横斜皆十五 |

依赖链是锁死的：井→银钥→绣楼；灯阵→金钥→殡房；启棺需压襟刀（绣楼床底）；后台需铜钥（戏台唱完）；昭穆正位→神龛暗格→镇魂匣。每破一道机关，宅门自松一道闩；九闩尽落，方以九宫算开最后一道。

## 内容说明

含惊吓、幽闭、民俗恐怖与死亡描写，建议戴耳机、关灯游玩。

三位女性角色——冥婚新娘苏婉娘（廿二）、鬼媒人柳三娘（四十）、青衣旦阮香绫（廿三）——**均为成年人设**，其"魅惑"落在声线、身段、构图与暧昧而危险的台词上，作为压迫感的一部分呈现，不含露骨内容。作品中无未成年角色。

冥婚是历史上真实存在并被历代朝廷明令禁止的陋习，本作把它作为恐怖题材的文化背景加以批判性使用，不美化该习俗。
